## Typeface

Each Typography variation has been selected to provide structure, hierarchy, and provide legibility for users.

The primary font for all HL community projects is "Archivo". Different variations of this font are used to denote different levels of a page or app.

![](/assets/archivo-green.webp)

### Headings

All major headings or top level hierarchical writing use the BOLD variation of Archivo with a variable font axis width set to 120%.

### Sub-Headings

All sub headings or upper (but not top) level hierarchical writing use the BOLD variation of Archivo WITHOUT a variable font axis width set to 120%. As the sub headings progress through the hierarchy, the boldness is not taken away, however the font size gradually shrinks until the sub heading font size is the same as the standard text font size.

### Standard Text

All standard text within HL community projects use the REGULAR variation of Archivo WITHOUT any changes or variations to the default font.
