There are many ways to post images in an update.

For example...

## From a URL

Images can be embedded from a URL, like this:

[![Aerial view of winding road through green rice terraces](https://images.unsplash.com/photo-1787540757892-cab3118bd223?q=80&w=2274&auto=format&fit=crop&ixlib=rb-4.1.0&ixid=M3wxMjA3fDB8MHxwaG90by1wYWdlfHx8fGVufDB8fHx8fA%3D%3D "Image From Unsplash URL")](https://unsplash.com/photos/terraced-rice-fields-with-dirt-road-7lK0bpUj8AA)

They're treated like any other image. You can add alt text, a title or a link.

## Uploading an Image

You're more likely to upload an image from your own device. Here I've already configured some basic transformations to ensure the image is formatted as a lossless \`.webp\` file to optimize for the web. 

Let's test by uploading an image:
