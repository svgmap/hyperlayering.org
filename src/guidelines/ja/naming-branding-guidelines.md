## 1.目的

本ガイドラインは、Hyper Layeringを中心として今後展開される技術、アーキテクチャ、プロダクト、プロジェクト、コミュニティについて、一貫した名称とブランド体系を構築することを目的とします。

今後、Hyper Layeringの考え方をもとにさまざまな技術やプロジェクトが展開されることを想定し、正式名称における用語の使い分けと、ブランド名称における共通ルールをあらかじめ整理します。

本ガイドラインでは、以下の2つを基本原則とします。

Naming Rule：正式名称では、意味に応じて Hyper Layering / Hyper Layeredを適切に使い分ける。

Brand Rule：ブランド名称では、Hyper Layeringの思想・技術を共有するブランドファミリーを示す共通名称として HLを使用する。

この2つを分けて考えることで、英語としての意味の正確さと、ブランドとしての一貫性の両立を図ります。

## 2.コアコンセプト：Hyper Layering

Hyper Layeringを、プロジェクトおよびブランド全体を支えるコアコンセプトとします。

Hyper Layeringとは、Web上に分散して存在するさまざまな情報やデータを、一か所に集約することなく、レイヤとしてつなぎ、重ね合わせ、組み合わせて利用するという考え方です。

Hyper Layering = Concept / Approach / Process

Hyper Layeringは、特定の地図やアプリケーションだけを指すものではなく、分散した情報を相互につなぎ、必要に応じて組み合わせて利用するための、より広い技術的・概念的な考え方として位置づけます。

## 3. Naming Rule：「Layering」と「Layered」の使い分け

正式名称では、それぞれの意味に応じて Layeringと Layeredを使い分けます。

### Layering

Layeringは、レイヤをつなぎ、重ね、組み合わせる「考え方・行為・プロセス・アプローチ」を表します。

- Hyper Layering
- Hyper Layering Architecture
- Hyper Layering Community

### Layered

Layeredは、Hyper Layeringの考え方によって構成・実現された「状態・成果物・プロダクト・システム」を表します。

- Hyper Layered Map
- Hyper Layered Knowledge Network
- Hyper Layered Digital Twin

Hyper Layering → Concept / Approach / Process

Hyper Layered → Product / System / Outcome

この使い分けは、正式名称における意味を明確にするための Naming Ruleとします。

## 4. Brand Rule：共通ブランド「HL」の考え方

HLは、Hyper Layeringの思想・技術を共有する技術、プロダクト、プロジェクトを共通して識別するためのブランド名称として使用します。

正式名称では、意味に応じて Hyper Layeringと Hyper Layeredを使い分けますが、ブランド名称における HLは、この文法上の違いを表すものではありません。

Layering / Layered →正式名称において、それぞれの意味を正確に表現するための言葉

HL → Hyper Layeringの思想・技術を共有するブランドファミリーを示す共通名称

例えば、HLMap — Hyper Layered Mapの場合、Hyper Layered Mapが正式名称であり、HLMapがブランド名称です。

ここでHLは「Hyper Layered」の文法的な略語ではなく、そのプロダクトが Hyper Layeringのブランドファミリーに属していることを示すブランド識別子として機能します。

この考え方により、今後新しいプロダクトやプロジェクトが生まれた場合も、HL + [Name]を共通のブランド体系として使用することができます。

## 5.ブランド体系

| **分類** | **正式名称** | **ブランド名称／略称** |
| Core Concept | Hyper Layering | Hyper Layering |
| Architecture | Hyper Layering Architecture | HLA |
| Community | Hyper Layering Community | Hyper Layering Community / HLC |
| Map / Product | Hyper Layered Map | HLMap |
| Knowledge Concept | Hyper Layered Knowledge Network | HLKN |

重要なのは、正式名称とブランド名称を必ずしも機械的な頭文字の対応関係にしないことです。正式名称は意味を正確に表現し、ブランド名称では HLを共通のブランド識別子として使用します。

## 6. HLMap

SVGMapの新しい名称として、HLMap — Hyper Layered Mapを使用します。

Hyper Layered Mapは、地図を基盤として、Web上に分散するさまざまな情報レイヤを重ね合わせ、組み合わせて利用できるというプロダクトの特性を表します。

正式名称では、この「複数の情報レイヤを組み合わせて利用できるMap／システム」という状態を表すため Layeredを使用します。一方、ブランド名称では、Hyper Layeringファミリーの共通ブランド識別子である HLを使用し、HLMapとします。

Full Name：Hyper Layered Map

Brand Name：HLMap

## 7. SVGMapからHLMapへの移行

SVGMapは長年使用されてきた名称であり、既存ユーザーや関係者との連続性を維持するため、一定の移行期間は旧名称を併記します。

- 正式な説明：HLMap (formerly SVGMap)
- 日本語：HLMap（旧称：SVGMap）
- 展示・図版・短い紹介文：HLMap (SVGMap)

移行期間終了後は、原則として HLMapに統一します。

## 8. Hyper Layering Community

コミュニティ名称は、Hyper Layering Communityとします。

Communityは特定のプロダクトだけを対象とするものではなく、Hyper Layeringという技術・思想・アプローチそのものを研究、開発、実践、普及していく活動主体として位置づけます。そのため、正式名称には、成果物や状態を表す Layeredではなく、活動・考え方を表す Layeringを使用します。

対外的な表記例：WebDINO Japan × Hyper Layering Community

## 9.今後の命名原則 Naming Rule

Hyper Layering → Concept / Approach / Process

Hyper Layered → Product / System / Outcome

### Brand Rule

HL = Common Brand Identifier for the Hyper Layering Family

ブランド名称では、原則として HL + [Name]というブランド体系を使用します。

この2つのルールを分けて運用することで、英語としての意味を正確に保ちながら、個々の技術やプロダクトがすべて Hyper Layeringという共通の思想・技術体系に属していることを示す、一貫したブランド体系を構築します。

## 10.本ガイドラインの位置づけ

本ドキュメントは Draft 0.1とし、Hyper Layering Communityのメンバーによる議論・検討を行うためのベースラインとします。

本Draftでは、Naming Rule（Layering / Layeredの意味上の使い分け）と、Brand Rule（HLをHyper Layeringファミリーの共通ブランド識別子として使用すること）を基本原則として整理しています。

今後、コミュニティ内での議論を通じてこれらの原則を検証するとともに、ロゴ、タイポグラフィ、カラー、表記方法、プロジェクト名称、Webサイト、展示、プレゼンテーション等での使用方法についても検討を進めます。最終的には、Hyper Layeringに関する技術・プロジェクト・コミュニティ全体に適用できる、包括的なブランドガイドラインへ発展させることを目指します。
